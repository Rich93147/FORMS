# Roadmap

1. Validate Python access to the Kinect v2 (SDK / wrapper).
2. Build loaders and skeleton normalization; test on MSRC-12.
3. Segment repetitions and extract squat features (KIMORE, UI-PRMD).
4. Train and evaluate form-error model against the metric targets.
5. Validate Kinect joint angles against Vicon (UI-PRMD).
6. Real-time audio and visual feedback for squats.
7. Extend to barbell rows and other exercises; later, webcam support.
